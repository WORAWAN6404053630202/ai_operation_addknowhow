Slot Mapping — 9-Step Matching (regex → LLM)

/* _map_pending_slot_reply() — hierarchy of matching strategies */ 1. Parse index number (เลขตัวเลือก) 2. Area measurement ("7.8 ตรม" → deterministic math, ไม่ให้ LLM เดา) 3. Exact / contains match 4. Stripped match (ตัด ครับ/ค่ะ + prefix "ต้องการ/สมัคร") 5. Numeric area compare ("8.9 ตรม" vs "น้อยกว่า 200 ตร.ม.") 6. Free-text for topic (topic key → accept any text) 7. Multi-select check (LLM: does user want ALL options?) 8. LLM slot mapper (confidence ≥ 0.60) 9. Fuzzy bigram match (threshold 0.50) → Error: "กรุณาตอบเป็นตัวเลขตามตัวเลือกครับ"

RAG Pipeline — 3-Level Retrieval
Hybrid Search + Iterative Gap-Fill + Cross-Encoder Reranking
Round 1: Base + Hybrid ├─ Query expansion: SYNONYM_PATTERNS (Thai↔English bridging) ├─ Append slot context (entity_type, registration_type ใน query string) ├─ BM25 (PyThaiNLP newmm) + Dense (e5-large) → RRF fusion (k=60) └─ Apply metadata_filter (Chroma where clause) + similarity ≥ 0.6 Round 2: Anchor Enrichment ├─ ดึง anchor: license_type / operation_topic / main_topic จาก top doc ├─ Re-query: original + anchor └─ Dedup by page_content hash Round 3: Gap-Fill (Iterative) ├─ _check_field_coverage(): operation_steps, fees, identification_documents, duration ├─ ขาด ≥ 2 fields → re-query: original + missing_terms └─ Dedup อีกรอบ Post-Processing: ├─ Metadata Boost: +0.25 ถ้า operation_topic/sub_topic/license_type match query ├─ Sibling completion: fetch ALL docs ใน (license_type, operation_by_department) ├─ Cross-encoder Reranker: BAAI/bge-reranker-v2-m3 ├─ Operation intent filter: exclude แก้ไข/ยกเลิก docs เมื่อ query = new-reg └─ Cap: Practical max 6 docs × 1,000 chars | Academic max 12 docs × 700 chars

Metadata Filter Fallback Chain

Combined: {"$and": [{"entity_type_normalized": "นิติบุคคล"}, {"location": "กรุงเทพฯ"}]} → fallback: {"entity_type_normalized": "นิติบุคคล"} → fallback: {"location": "กรุงเทพฯ"} → fallback: unfiltered (0 docs = never say "ไม่พบข้อมูล" at menu stage)

🔎 Hybrid Search Details

BM25: PyThaiNLP newmm tokenizer, Okapi BM25, thread-safe singleton index

Dense: multilingual-e5-large embeddings

RRF: score(d) = Σ 1/(k+rank_i), k=60

BM25-only hits: marked _bm25_hit=True, not dropped for low dense score

🎯 Reranker Details

Model: BAAI/bge-reranker-v2-m3 (multilingual)

Type: Cross-encoder (pairwise query-doc scoring)

Config: RERANKER_ENABLED=true, TOP_K=10

Fallback: ถ้า error → return original docs unchanged
